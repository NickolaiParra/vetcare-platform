# Workshop 1: Requirements Analysis and User Stories

Deadline: September 30th, 2026, 23:00.

This folder contains the deliverable of Workshop 1 for VetCare. The full document is compiled in a single PDF, and this README points to each of its sections.

## Files

| File | Description |
|---|---|
| `Workshop-1.pdf` | Complete deliverable (single PDF) |

## Sections

### 1. Requirements

32 functional requirements (FR_01 to FR_32) and 10 non-functional requirements (NFR_01 to NFR_10), grouped by module:

- Module 1: Authentication & Access Control (RBAC)
- Module 2: Patient & Client Management (CRM & Clinical Records)
- Module 3: Space & Appointment Management
- Module 4: Pharmacy & Inventory Management
- Cross-cutting Non-Functional Requirements

### 2. User Stories

20 user stories with acceptance criteria (Given / When / Then), organized by role: Pet Owner, Receptionist, Veterinarian, Veterinary Assistant, Clinic Administrator and All Users.

### 3. User Story Mapping

Stories are grouped by activity (Access & Accounts, Clients & Patients, Appointments, Hospitalization, Pharmacy & Inventory) and prioritized into three releases:

| Release | Focus | Stories |
|---|---|---|
| Release 1 | Core clinic operations | 9 |
| Release 2 | Hospitalization and pharmacy | 8 |
| Release 3 | Owner portal and reminders | 3 |

### 4. References

Sources that influenced the writing of the user stories, acceptance criteria and story map.

### 5. Use of Artificial Intelligence

Declaration of the use of an AI assistant as a support tool during the preparation of this workshop.
