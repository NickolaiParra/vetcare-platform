# Workshop 2: Design Artifacts and System Modeling

This folder contains the deliverable of Workshop 2 for VetCare. The full document is compiled in a single PDF, and this README points to each of its sections.

## Files

| File             | Description                       |
| ---------------- | --------------------------------- |

## Sections

### 1. System Domain

System context, actor characterization and business rules.

### 2. CRC Cards

Main classes of the system with their responsibilities and collaborators, one card per class.

### 3. Class Diagram

UML class diagram with attributes, methods and relationships.

### 4. Relational Database Model

Relational schema with tables, primary and foreign keys, and relationships.

### 5. Mockups

Wireframes of the main screens of the application, with a brief explanation of the purpose of each one.

### 6. References and Use of Artificial Intelligence

Sources that influenced the design decisions and declaration of the use of an AI assistant.****
